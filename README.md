# wtgspain

REST API на Laravel 12 — імпорт пропозицій житла, пошук найдешевшої актуальної пропозиції, бронювання.

## Статус

Каркас Laravel 12 + Docker-оточення (php-fpm/nginx/mysql/redis/queue) розгорнуто. Реалізація йде по TDD (див. `CLAUDE.md`).

Повний README (встановлення, команди, пояснення ідемпотентності імпорту й concurrency-захисту бронювання) — після завершення реалізації.
